# DD2gether

Full network co-op mod for Dragon's Dogma 2. Play with up to 
4 players, each controlling their own Arisen, with synchronized 
enemies, NPCs, combat and environment interactions.

🐸 This is an early **Alpha** — expect bugs and rough edges. 
Your feedback and bug reports directly shape where the mod 
goes from here.

## Download

Grab the latest release from the [Releases page](https://github.com/But-Frog/dd2-together-release/releases).

## Installation

Full step-by-step instructions with screenshots are available here:
👉 [DD2gether Install Guide](https://docs.google.com/document/d/1bRglXD36HPN4g5TYo_TlREpYwJ6zcrx6RJJ25HusMEA)

For a video tutorial click here:
[DD2gether Install Video-Guide](https://youtu.be/T3TtdsNUY48)

**Please read the full guide before playing** — it covers:
- Backing up your save (important, the mod overwrites your Pawn)
- Installing the mod and connecting via Steam
- Disabling other mods during testing
- Uninstalling / switching back to singleplayer
- Reporting bugs

## Important Notes

- Mod compatibility has not been tested — disable other mods 
  if you run into issues
- Quests and some late-game content (e.g. Unmoored World) are 
  not yet tested — current focus is core gameplay sync and stability
- Please back up your save before playing

## Bug Reports

Found an issue? Please report it in the `#bug-reports` channel 
on Discord — include a saved bug report (see install guide 
for how). This helps a lot with improving stability.
